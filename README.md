# Android Practice Projects

Smaller Android apps I built in Java while learning Android development at Eduvos. Each folder is its own Android Studio project.

| Project | What it is |
| --- | --- |
| `AssessmentCalculator` | Calculates CAS and final averages from entered marks |
| `ITMBA2-B33` | Weekly class exercises, including calculator apps |
| `B3W4MissedLesson` | Saves, loads, and clears user data (name and age) on the device |

For my full Android app, see [TripBuddy](https://github.com/qwerty-jaq/tripbuddy-android).

## How to run

1. Open one of the project folders (not this top folder) in **Android Studio**
2. Wait for Gradle to sync
3. Press **Run ▶**
